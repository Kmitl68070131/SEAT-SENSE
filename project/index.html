04 / SYSTEM CALCULATIONS

หลักการคำนวณของระบบ

สมการที่ใช้จริงในโค้ด Arduino เพื่อวัดอุณหภูมิ ตรวจจับระยะทาง และสร้างรหัส PIN

ARDUINO × MATHEMATICS
01 / TEMPERATURETMP36

การคำนวณอุณหภูมิ

TMP36 ส่งค่าแรงดันไฟฟ้าแบบแอนะล็อกให้ Arduino อ่านผ่านขา A0 แล้วแปลงเป็นองศาเซลเซียส

แปลงค่า ADC เป็นแรงดันไฟฟ้า
V = (ADC × 5.0) / 1023
แปลงเป็นอุณหภูมิ (°C)
T = ((V − 0.5) × 100) + 20
  • ADC — ค่าที่อ่านได้จากเซนเซอร์ (ค่าเฉลี่ย 10 ครั้ง)
  • V — แรงดันไฟฟ้า หน่วยโวลต์ (V)
  • T — อุณหภูมิ หน่วยองศาเซลเซียส (°C)

หมายเหตุ: ค่า +20°C เป็นค่าชดเชยที่กำหนดเพิ่มในโค้ดของโครงงาน ไม่ใช่สูตรมาตรฐาน TMP36 และควรสอบเทียบกับอุณหภูมิจริง

ตัวอย่างจาก Arduino.ino
float voltage = avgRaw * (5.0 / 1023.0);
float rawTemp = ((voltage - 0.5) * 100.0) + 20.0;
smoothedTemp = (0.05 * rawTemp)
             + (0.95 * smoothedTemp);

ค่าที่วัดได้ถูกกรองด้วย Exponential Moving Average (EMA) เพื่อลดความผันผวนก่อนนำไปแสดงผล

02 / DISTANCEHC-SR04

การคำนวณระยะทาง

เซนเซอร์อัลตราโซนิกวัดเวลาที่คลื่นเสียงเดินทางไปกระทบวัตถุและสะท้อนกลับ เพื่อคำนวณระยะห่างจากผู้ใช้งาน

สูตรระยะทาง (เซนติเมตร)
d = (t × 0.0343) / 2
ตัวอย่าง เมื่อ t = 1,000 µs
d = 17.15 cm
  • d — ระยะทาง หน่วยเซนติเมตร (cm)
  • t — เวลาเดินทางไป–กลับของคลื่นเสียง หน่วยไมโครวินาที (µs)
  • 0.0343 — ความเร็วเสียงโดยประมาณ (cm/µs) และหาร 2 เพราะคลื่นเสียงเดินทางสองเที่ยว

การใช้งานจริง: โค้ดกำหนดเกณฑ์ 80 cm หากเซนเซอร์ตรวจพบผู้ใช้อย่างน้อยหนึ่งตำแหน่งภายในระยะนี้ ระบบจะถือว่ายังมีคนอยู่ที่โต๊ะ

ตัวอย่างจาก Arduino.ino
long duration = pulseIn(echoPin, HIGH, 30000);
if (duration == 0) return -1.0;
return (duration * 0.0343) / 2.0;

หากไม่ได้รับสัญญาณสะท้อนภายในเวลาที่กำหนด ฟังก์ชันจะคืนค่า −1 เพื่อระบุว่าอ่านระยะไม่ได้

03 / PSEUDORANDOMLCG

การสร้างรหัส PIN แบบสุ่มเทียม

ระบบใช้ Linear Congruential Generator (LCG) คำนวณค่าจาก Seed เดิมเพื่อสร้างรหัส PIN 4 หลักสำหรับยืนยันการจองโต๊ะ

สมการ Linear Congruential Generator
Xn+1 = (aXn + c) mod m
ค่าคงที่ในโปรเจกต์
a = 1,664,525 · c = 1,013,904,223
m = 9,999
  • Xn — ค่า Seed หรือผลลัพธ์จากรอบก่อน
  • a, c, m — ตัวคูณ ค่าบวก และตัวหารเอาเศษตามลำดับ
  • PIN — ค่าที่ได้ถูกจัดรูปแบบเป็นตัวเลข 4 หลัก เช่น 0042

ในโค้ดจริง: การคูณและบวกใช้ชนิด uint32_t จึงอาจมีการวนค่าที่ 32 บิตก่อนทำ % 9999 และค่าเริ่มต้นถูกกำหนดจาก millis() + analogRead(A0)

ตัวอย่างจาก Arduino.ino
lcg_seed = (A * lcg_seed + C) % m;
char pinBuf[5];
snprintf(pinBuf, sizeof(pinBuf), "%04lu",
         (unsigned long)lcg_seed);

LCG เป็นการสุ่มเทียมที่คาดเดาได้ จึงเหมาะกับการศึกษาหลักการมากกว่าระบบที่ต้องการ PIN ความปลอดภัยสูง

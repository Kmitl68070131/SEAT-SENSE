## 📖 เกี่ยวกับโปรเจกต์

**S.E.A.T (Smart Ergonomic & Available Table)** เป็นต้นแบบระบบบริหารจัดการโต๊ะในห้องสมุดที่ผสานเทคโนโลยี IoT เข้ากับเว็บแอปพลิเคชัน ผู้ใช้สามารถตรวจสอบสถานะและจองโต๊ะผ่านเว็บ รับรหัส PIN เพื่อยืนยันการใช้งานที่ Keypad และตั้งเวลาแจ้งเตือนให้พักจากการนั่งทำงานได้

แต่ละโต๊ะรองรับ **2 คน** โดยจองทั้งโต๊ะและใช้ **PIN เดียวต่อการจอง** ระบบใช้ Ultrasonic Sensor จำนวน 2 ตัวตรวจจับวัตถุบริเวณที่นั่ง เพื่อประกอบการคืนโต๊ะอัตโนมัติเมื่อไม่พบการใช้งานตามเงื่อนไขที่กำหนด

> Ultrasonic Sensor ตรวจวัดระยะห่างของวัตถุ จึงไม่สามารถแยกคนออกจากสิ่งของได้อย่างแน่นอน ประสิทธิภาพขึ้นอยู่กับตำแหน่งติดตั้งและสภาพแวดล้อม

## 🎯 จุดประสงค์ของโปรเจกต์

1. **อำนวยความสะดวกในการค้นหาโต๊ะ**  
   ตรวจสอบสถานะผ่านเว็บ ลดเวลาเดินหาโต๊ะอ่านหนังสือ โดยเฉพาะช่วงใกล้สอบ

2. **ลดปัญหาการจองโต๊ะทิ้งไว้**  
   คืนโต๊ะอัตโนมัติเมื่อไม่ตรวจพบการใช้งานเกินเวลาที่กำหนด

3. **ส่งเสริมพฤติกรรมการพักระหว่างทำงาน**  
   ตั้งเวลาแจ้งเตือนให้ผู้ใช้งานลุกเปลี่ยนอิริยาบถหลังนั่งทำงานต่อเนื่อง

4. **เป็นพื้นฐานสำหรับการบริหารจัดการพื้นที่**  
   รองรับการต่อยอดเก็บประวัติและวิเคราะห์การใช้งานในอนาคต

## 🚀 ขั้นตอนการใช้งาน

1. เปิด **เว็บจองโต๊ะ** ผ่านคอมพิวเตอร์หรือโทรศัพท์
2. ไปที่แท็บ **เลือกโต๊ะ**
3. เลือกโต๊ะที่มีสถานะ **พร้อมใช้งาน**
4. กด **จองโต๊ะนี้** แล้วรอการยืนยันจากบอร์ด
5. นำ PIN 4 หลักที่ได้รับไปกรอกบน Keypad ของโต๊ะ แล้วกด **D**
6. หลังยืนยันสำเร็จ ระบบแสดงหน้าต้อนรับและเข้าสู่เมนู
7. กด **A** เพื่อดูอุณหภูมิ หรือ **B** เพื่อตั้งเวลาเตือนพัก
8. กรอกเวลาเป็นนาที แล้วกด **D** เพื่อเริ่มนับถอยหลัง
9. เมื่อจอแสดง **Move Around** ให้ลุกพักและเปลี่ยนอิริยาบถ
10. เมื่อเลิกใช้งาน กด **คืนโต๊ะ / ยกเลิกการจอง** บนเว็บ หรือให้ระบบคืนโต๊ะตามเงื่อนไขอัตโนมัติ

> สามารถจัดทำ QR Code ที่เชื่อมไปยังเว็บจองโต๊ะ เพื่อติดไว้บริเวณโต๊ะหรือทางเข้าห้องสมุดได้

## 🛠️ การติดตั้งและตั้งค่า

### 1. ดาวน์โหลดโปรเจกต์

ดาวน์โหลด ZIP จาก GitHub หรือใช้คำสั่ง:

```bash
git clone https://github.com/Kmitl68070131/SEAT-SENSE.git
```

### 2. เตรียม Arduino IDE

1. ติดตั้ง Arduino IDE
2. เปิด Boards Manager และติดตั้ง **Arduino UNO R4 Boards**
3. เลือกบอร์ด **Arduino UNO R4 WiFi**
4. เลือกพอร์ตที่เชื่อมต่อกับบอร์ด

### 3. ติดตั้งไลบรารี

ติดตั้งผ่าน Library Manager:

- **PubSubClient**
- **LiquidCrystal_I2C**

ส่วน `WiFiS3` และ `Wire` มากับแพ็กเกจบอร์ด

### 4. ตั้งค่า Firmware

เปิดไฟล์ [`Arduino/Arduino.ino`](Arduino/Arduino.ino) แล้วแก้ค่าตามชื่อของตัวแปร:

| ตัวแปร | สิ่งที่ต้องตั้งค่า |
| --- | --- |
| `SECRET_SSID` | ชื่อ Wi-Fi |
| `SECRET_PASS` | รหัสผ่าน Wi-Fi |
| `TABLE_BOARD_ID` | ชื่อโต๊ะ ต้องไม่ซ้ำกับโต๊ะอื่น เช่น `A0`, `A1`, `A2` |
| `MQTT_BROKER` | ที่อยู่ MQTT Broker |
| `MQTT_PORT` | พอร์ต MQTT ของบอร์ด |
| `DISTANCE_THRESHOLD` | ระยะตรวจจับ ค่าในโค้ดปัจจุบัน 80 ซม. |
| `AUTO_LOGOUT_TIMEOUT` | เวลาก่อนคืนโต๊ะอัตโนมัติ ค่าในโค้ดปัจจุบัน 30 วินาที |
| `officeSyndromeDuration` | เวลาเตือนพักเริ่มต้น 45 นาที ปรับผ่าน Keypad ได้ |

ตัวอย่างการตั้งค่าเครือข่าย:

```cpp
const char* SECRET_SSID = "YOUR_WIFI_NAME";
const char* SECRET_PASS = "YOUR_WIFI_PASSWORD";

const char* MQTT_BROKER = "broker.hivemq.com";
const int MQTT_PORT = 1883;

const char* TABLE_BOARD_ID = "A0";
```

### 5. Upload และทดสอบ

1. ต่ออุปกรณ์ตามตารางการต่อสาย
2. เชื่อมต่อบอร์ดกับคอมพิวเตอร์
3. กด Verify และ Upload
4. เปิด Serial Monitor ที่ **9600 baud**
5. รอการเชื่อมต่อ Wi-Fi และ MQTT
6. เปิดเว็บจองโต๊ะ
7. ทดสอบจอง รับ PIN กรอก PIN และตั้งเวลา

## 🔄 เงื่อนไขการคืนโต๊ะอัตโนมัติ

ระบบตรวจระยะจาก Ultrasonic Sensor ทั้งสองตัวประมาณทุก 1 วินาที

- หากเซนเซอร์ **ตัวใดตัวหนึ่ง** อ่านระยะได้มากกว่า 0 และไม่เกิน **80 ซม.** จะถือว่ายังมีการใช้งานโต๊ะ
- เมื่อมีการตรวจพบ ระบบจะรีเซ็ตเวลารอคืนโต๊ะ
- การกด Keypad จะรีเซ็ตเวลารอคืนโต๊ะเช่นกัน
- หากโต๊ะมีการจองหรืออยู่ระหว่างใช้งาน และไม่พบการใช้งานครบ **30 วินาที** ระบบจะคืนโต๊ะเป็น `VACANT`
- เมื่อไม่มี Echo เซนเซอร์จะคืนค่า `-1` และไม่นับว่าเป็นการตรวจพบ

> ค่า 30 วินาทีเหมาะสำหรับการสาธิต ควรปรับให้เหมาะสมก่อนใช้งานจริง และตรวจสอบการทำงานเมื่อเซนเซอร์ขัดข้อง

| อุปกรณ์ | Broker | รูปแบบ | Port |

```text
smartdesk/<TABLE_BOARD_ID>/<type>
```

### Topics ที่ใช้

| Topic | ทิศทาง | ข้อมูล |
| --- | --- | --- |

| `smartdesk/<id>/temp` | บอร์ด → เว็บ | อุณหภูมิหน่วย °C |
| `smartdesk/<id>/pin` | บอร์ด → เว็บ | PIN 4 หลัก หรือ `----` เมื่อเคลียร์รหัส |
| `smartdesk/<id>/online` | บอร์ด → เว็บ | `ONLINE` / `OFFLINE` |
| `smartdesk/<id>/command` | เว็บ → บอร์ด | `BOOK` / `LOGOUT` |

### ตัวอย่างสำหรับโต๊ะ A0

```text
smartdesk/A0/status
smartdesk/A0/temp
smartdesk/A0/pin
smartdesk/A0/online
smartdesk/A0/command
```

- บอร์ดส่งอุณหภูมิและข้อความ `ONLINE` ทุกประมาณ **5 วินาที**
- สถานะ PIN และการเชื่อมต่อใช้ **Retained Messages**
- ใช้ **Last Will** เพื่อแจ้ง `OFFLINE` เมื่อ Broker ตรวจพบว่าบอร์ดขาดการเชื่อมต่อ
- เว็บส่ง `BOOK` เพื่อขอจอง และ `LOGOUT` เพื่อคืนโต๊ะ

## 🧪 ข้อสังเกตของต้นแบบ

- การอ่าน TMP36 ในโค้ดมีค่าชดเชย **+20°C** ควรเทียบกับเครื่องวัดอ้างอิงและปรับค่าก่อนใช้งาน
- Ultrasonic Sensor อาจตรวจพบสิ่งของแทนคน จึงควรทดสอบตำแหน่งติดตั้งจริง
- เว็บต้องเชื่อมต่อ Broker จึงจะรับสถานะและส่งคำสั่งไปยังบอร์ดได้
- Public Broker ใช้ร่วมกับบุคคลอื่น และ PIN ถูกส่งผ่าน MQTT ระบบปัจจุบันจึงเหมาะกับการสาธิต
- ก่อนนำไปใช้งานจริง ควรเพิ่มการยืนยันตัวตน การกำหนดสิทธิ์ Topic และการเข้ารหัสการเชื่อมต่อของบอร์ด
- ระบบเตือนพักเป็นเครื่องมือช่วยเตือนพฤติกรรม ไม่ใช่อุปกรณ์วินิจฉัยหรือรับประกันการป้องกันโรค
